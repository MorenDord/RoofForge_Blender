# RoofForge 0.1.0 alpha — установка и проверка

Это тестовая сборка для Blender 5.0+. Она нужна, чтобы проверить реальную работу базового инструмента и собрать обратную связь. Это ещё не обещанная версия RoofForge 1.0.

## Установка

1. Скачай файл roof_forge-0.1.0.zip из раздела **Artifacts** последнего успешного workflow **RoofForge tests** в GitHub:  
   https://github.com/MorenDord/RoofForge_Blender/actions
2. Не распаковывай ZIP.
3. В Blender открой **Edit → Preferences → Get Extensions**.
4. Открой меню установки в правом верхнем углу окна Extensions и выбери **Install from Disk…**.
5. Укажи roof_forge-0.1.0.zip, установи и включи RoofForge.
6. В 3D View открой боковую панель клавишей **N**, вкладка **RoofForge**.

## Первый тест — простой скатный объём

1. Создай обычный Mesh Plane. Он должен находиться в XY-плоскости.
2. Перейди в Edit Mode, включи Edge Select и выдели все четыре граничных ребра.
3. В панели RoofForge оставь Pitch = 35° и Thickness = 0.12 (или укажи свои значения).
4. Нажми **Validate Roof Boundary**. Ожидается успешная проверка.
5. Нажми **Create Roof Shell**.
6. Перейди в Object Mode. Должен появиться отдельный объект Plane_RoofForge. Исходная плоскость должна остаться на месте и не измениться.

Повтори тест, выделив замкнутый контур в Object Mode. Дополнительно можно проверить выпуклый прямоугольник или трапецию с 5–6 вершинами.

## Что в этой версии пока не проверять как обещанную функцию

- Не рассчитывай на корректную генерацию вогнутых L/U-контуров: weighted wavefront пока не подключён к кнопке Create Roof.
- Не меняй pitch отдельных скатов: UI пока применяет одно значение ко всем рёбрам.
- Overhang и Live Update пока не являются рабочими функциями.
- Не ожидай автоматических ridge/valley/hip-профилей, standing seams, UV или LOD.
- Не используй неравномерный масштаб объекта без предварительного Apply Scale.

Если контур не подходит текущему решателю, операция должна завершиться с сообщением об ошибке, а не создавать оболочку с внутренними разрывами.

## Что прислать после теста

- Точную версию Blender (Help → About Blender), ОС и версию RoofForge 0.1.0.
- Тип контура и число вершин.
- Значения Pitch и Thickness.
- Что нажимал и какой результат ожидал/получил.
- Скриншот панели и результата. При ошибке — точный текст из Blender System Console.
- По возможности — небольшой .blend с тестовой геометрией.

Особенно полезно проверить: доступна ли вкладка RoofForge, проходит ли Validate, создаётся ли отдельный объект, совпадает ли его положение с источником и остаётся ли исходная геометрия неизменной.

## Удаление тестовой версии

В Preferences → Get Extensions найди RoofForge и отключи/удали расширение. Перед установкой другой тестовой сборки удали предыдущую, чтобы не спутать версии.
