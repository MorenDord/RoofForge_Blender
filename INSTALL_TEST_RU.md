# RoofForge 0.2.2 — установка и тестирование

Это экспериментальная сборка для Blender 5.0+. В панели RoofForge появились два независимых способа отображения схемы:

- **Raster preview (PNG)** — прежняя миниатюра в панели RoofForge. PNG обновляется отложенно после короткой паузы.
- **Vector overlay (Viewport)** — схема рисуется напрямую GPU-линиями и текстом в окне 3D Viewport. Для этого режима PNG не создаётся и не пересчитывается.

Можно включать каждый режим независимо, оба одновременно или выключить оба. По умолчанию включён только PNG, чтобы сохранить привычное поведение.

## Установка

1. Удали предыдущую тестовую версию RoofForge в **Edit → Preferences → Get Extensions**.
2. Открой Actions: https://github.com/MorenDord/RoofForge_Blender/actions
3. Выбери последний успешный workflow **RoofForge tests** на ветке `feature/0.2.0-arbitrary-contours-live-pitch`.
4. Скачай внешний архив `roof_forge-0.2.2-blender-5.0.1` и распакуй его один раз.
5. Установи внутренний `roof_forge-0.2.2.zip` через **Preferences → Get Extensions → Install from Disk…**. Внутренний ZIP не распаковывай.

## Проверка режимов отображения

1. Выдели Mesh-контур и нажми **Create / Update Roof**.
2. В блоке **Plan display** включи **Raster preview (PNG)**. Схема появится в панели RoofForge.
3. Выключи PNG и убедись, что миниатюра скрылась.
4. Включи **Vector overlay (Viewport)**. В нижней левой части окна 3D Viewport должна появиться отдельная векторная схема.
5. Меняй Pitch и параметры **Number size / Line thickness**. Векторная схема должна обновляться при перерисовке viewport без создания PNG.
6. Включи оба флажка одновременно: PNG остаётся в панели, вектор — в окне 3D Viewport.
7. Выключи оба: оба представления должны исчезнуть, генерация крыши и Live Update должны продолжить работать.

Векторный оверлей — экранная схема, а не объект сцены. Он закреплён в нижней левой части области 3D Viewport и не зависит от угла камеры.

## Проверка геометрии крыши

Остальные возможности генератора не изменились относительно 0.2.1: индивидуальные Pitch, толщина, свес с опцией Converge corners, Live Update, повторное создание после удаления крыши и перестройка после редактирования исходного контура в Edit Mode работают в прежнем объёме.

Положительный свес пока поддерживается только для выпуклых контуров. Вогнутые L/U-контуры поддерживаются при нулевом свесе; положительный свес для них будет отклонён.

## Что особенно проверить

- Сравни читаемость и резкость линий PNG и векторного режима.
- Проверь, что изменение Pitch обновляет вектор без заметной задержки.
- Сравни нагрузку при включённом только PNG, только векторе и обоих режимах.
- Проверь несколько окон 3D Viewport и изменение размеров области.
- Убедись, что после отключения Vector overlay схема исчезает, а после выключения аддона draw-handler корректно освобождается.

Если увидишь смещение, мерцание, зависание или неправильное масштабирование — приложи скриншот и файл .blend.
