# RoofForge 0.2.0-alpha.1 — установка и тестирование

Это ранняя тестовая сборка для Blender 5.0+. В ней уже можно проверить автоматическое чтение контура объекта, индивидуальные углы скатов, генерацию вогнутых крыш с карнизами постоянной высоты и обновление результата при изменении pitch. Это не законченная версия 1.0.

## Установка

1. Удали предыдущую версию RoofForge alpha в **Edit → Preferences → Get Extensions** (найди RoofForge и отключи/удали).
2. Открой страницу Actions: https://github.com/MorenDord/RoofForge_Blender/actions
3. Выбери последний успешный workflow **RoofForge tests** на ветке `feature/0.2.0-arbitrary-contours-live-pitch`.
4. В разделе **Artifacts** скачай внешний архив `roof_forge-0.2.0-alpha.1-blender-5.0.1.zip`.
5. Распакуй внешний архив один раз. Внутри будет `roof_forge-0.2.0-alpha.1.zip` и файл SHA256.
6. Внутренний `roof_forge-0.2.0-alpha.1.zip` **не распаковывай**.
7. В Blender открой **Edit → Preferences → Get Extensions**.
8. В меню установки выбери **Install from Disk…**, укажи внутренний ZIP, установи и включи RoofForge.
9. В 3D View нажми **N** и открой вкладку **RoofForge**.

## Первый тест — выпуклый контур

1. Создай Mesh с одним замкнутым контуром. Это может быть wire loop из рёбер или поверхность с одной внешней граничной петлёй.
2. Выдели только объект. Выделение вершин/рёбер не требуется.
3. Нажми **Load / Refresh Slope Angles**.
4. Убедись, что появилось нужное число полей `Edge 01`, `Edge 02` и т. д.
5. Установи индивидуальные углы. Например: 30°, 35°, 40°, 32°.
6. Оставь **Live Update** включённым.
7. Нажми **Validate Roof Boundary**, затем **Create / Update Roof**.

Должен появиться отдельный mesh-объект с закрытой толщиной. Исходная сетка не должна измениться.

## Второй тест — вогнутый L/U-контур

Для проверки нового алгоритма создай L- или U-образный замкнутый wire-контур, у которого все вершины лежат на одной высоте Z.

1. В Object Mode выбери объект.
2. Нажми **Load / Refresh Slope Angles**.
3. Задай разные углы хотя бы для нескольких скатов.
4. Проверь результат кнопкой **Validate Roof Boundary**.
5. Нажми **Create / Update Roof**.
6. После генерации измени один из углов. Через короткую задержку крыша должна перестроиться на месте, без появления второго объекта.
7. Измени Thickness: Live Update должен пересчитать оболочку.
8. Сравни положение исходного контура и крыши; исходный mesh остаётся нетронутым.

В этой версии номера скатов следуют детерминированному порядку обхода границы. Цветного выделения соответствующего ребра во viewport и графического плана крыши пока нет.

## Проверка 3D-контура с разной высотой Z

Для проверки старого 3D-пути попробуй выпуклый четырёх- или многоугольный контур с вершинами на разных высотах Z. RoofForge не должен сплющивать исходные координаты. Если исходные плоскости не дают непрерывную крышу, валидатор должен вернуть ошибку вместо повреждённого меша.

**Важно:** новый weighted wavefront в этой alpha работает только для контура с постоянной высотой карнизов. Вогнутые L/U-контуры с разными Z пока не являются поддерживаемым гарантированным случаем.

## Как работает Live Update

- Изменение любого индивидуального Pitch или Thickness планирует перестройку с debounce примерно 0,3 секунды.
- Геометрия строится и проверяется до замены mesh.
- Если новый результат невалиден, прежняя корректная крыша остаётся в сцене.
- Переименование исходного объекта или сгенерированной крыши останавливает Live Update. Это защищает от случайного изменения объекта после начала ручной доработки.
- Если число рёбер исходного контура изменилось, нажми **Load / Refresh Slope Angles** и проверь соответствие углов заново.

## Что пока не реализовано

- Поддержка абсолютно любых вогнутых контуров без ограничений по событиям; некоторые редкие комбинации одновременных событий ещё могут быть отклонены.
- Полноценная общая обработка вогнутых контуров с разной высотой карнизов.
- Цветная подсветка связи «номер ската ↔ ребро» и графическая карта pitch.
- Автоматические коньки, ендовы, standing seams, UV, LOD и экспорт.
- Дополнительные фасции, софиты и декоративные свесы.

## Что прислать после проверки

Для каждой проблемы полезно приложить:
- версию Blender (**Help → About Blender**) и ОС;
- количество рёбер и тип контура: выпуклый, L, U, multi-notch или произвольный;
- высоты Z вершин, если они различаются;
- список значений Pitch;
- скриншот результата и панели RoofForge;
- точный текст ошибки из Blender System Console;
- небольшой `.blend` с исходным контуром, если ошибка воспроизводится.

Особенно интересуют случаи, где:
- не совпадает номер ската и ожидаемое ребро;
- Live Update создаёт дубликат или не сохраняет последнюю крышу;
- крыша имеет разрыв, самопересечение или неверную плоскость ската;
- результат на L/U отличается от ожидаемого.

## Удаление alpha

В **Preferences → Get Extensions** отключи/удали RoofForge. Перед установкой следующей alpha рекомендуется удалить предыдущую тестовую версию.
