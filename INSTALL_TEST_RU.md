# RoofForge 0.4.2 — установка и тестирование

Экспериментальная сборка для Blender 5.0+. В этой версии исправлен путь построения свеса и упрощена панель RoofForge.

## Что изменилось

- Overhang строится вокруг поверхности исходной крыши полосами на тех же опорных плоскостях. Полная огибающая больше не пересчитывается на увеличенном контуре — это устраняет один из самых дорогих этапов прежнего пути.
- Одинаковый способ сборки свеса используется для выпуклых и вогнутых XY-контуров, в том числе для смешанных XYZ-высот карниза.
- Вогнутый контур с разной высотой вершин и положительным Overhang использует точный пространственный solver исходной поверхности. В обычном режиме без свеса этот тип контура пока остаётся ограничением.
- Соседние полосы автоматически сходятся на пересечении своих опорных плоскостей. Переключатель Converge corners удалён из панели.
- Live Update объединяет быстрые изменения параметров и запускает геометрию не раньше чем через 250 мс после последнего изменения.
- Roof Plan всегда отображается при существующей крыше. Убраны Show Preview, Debug UI Bounds, Copy debug text и сворачиваемые секции. Опциональные инструменты коньков, ендов и фальцев сохранены.

Свес корректен, если расширенный контур остаётся простым и полностью охватывает исходный контур. Если свес закрывает узкую выемку, пересекает сам себя или схлопывается, RoofForge сообщает об ограничении геометрии и сохраняет последнюю корректную крышу.

## Установка

1. Удали предыдущую тестовую версию RoofForge в **Edit → Preferences → Get Extensions**.
2. Открой Actions: https://github.com/MorenDord/RoofForge_Blender/actions
3. Выбери последний успешный workflow **RoofForge tests** на ветке \`feature/0.2.0-arbitrary-contours-live-pitch\`.
4. Скачай внешний архив \`roof_forge-0.4.2-blender-5.0.1\` и распакуй его один раз.
5. Установи внутренний \`roof_forge-0.4.2.zip\` через **Preferences → Get Extensions → Install from Disk…**. Внутренний ZIP не распаковывай.

## Проверка свеса

Проверь последовательно:

1. Выпуклый прямоугольник с одинаковыми и разными Pitch.
2. Плоский вогнутый L-контур.
3. Плоский вогнутый U-контур с умеренным свесом.
4. Вогнутый L/U-контур с разной высотой вершин и положительным Overhang.
5. Контур по часовой стрелке, чтобы проверить независимость от порядка обхода.

Для каждого случая проверь, что внешний край расширен, все грани остаются на своих опорных плоскостях, а shell закрыт. Затем измени Overhang и Pitch через Live Update и дождись короткой паузы после последнего движения слайдера.

Отдельно проверь слишком широкий свес на узком U-контуре: он должен быть отклонён с понятной ошибкой, без зависания Blender и без замены последней корректной крыши.

## Проверка интерфейса

- При существующей крыше Roof Plan должен отображаться автоматически, без переключателя Show Preview.
- Панель RoofForge и блоки деталей не должны требовать раскрытия дополнительных секций.
- На панели не должно быть Debug UI Bounds, Copy debug text или служебной строки выбора Python/Rust backend.
- Размер номеров и толщину линий плана по-прежнему можно настраивать.
- Опциональные переключатели Create ridges, Create valleys и Create standing seams управляют только соответствующей геометрией.

## Проверка Edit Mode Live Update

1. Создай крышу по замкнутому wire-контру, включи Live update.
2. В Edit Mode передвинь граничную вершину. После короткой паузы крыша и Roof Plan должны обновиться, не выходя из Edit Mode.
3. Выполни Subdivide на граничном ребре — должно добавиться поле Pitch с унаследованным значением.
4. Выполни Dissolve вставленной вершины — соответствующее поле Pitch должно исчезнуть, крыша должна пересобраться.

## Ограничения

- Поддерживается один простой замкнутый контур. Несколько отдельных контуров и отверстия не поддерживаются.
- Если offset пересекает сам себя, закрывает выемку или больше не содержит исходный контур, свес отклоняется.
- Вогнутые контуры с разной высотой вершин при нулевом Overhang пока остаются неподдержанным случаем.
- Экспериментальные одновременные события weighted-wavefront на сложных многовыемочных контурах могут быть отклонены; предыдущая корректная крыша сохраняется.
