# RoofForge 0.2.0-alpha.6 — установка и тестирование

Это ранняя тестовая сборка для Blender 5.0+. В ней можно проверить индивидуальные уклоны со свесом на плоских и неплоских выпуклых контурах, а также на вогнутых L/U-контурах, размеры в сантиметрах, повторное создание после удаления крыши и задержку Live Update в миллисекундах. Это не законченная версия 1.0. Максимальный размер контура — 64 ребра.

## Установка

1. Удали предыдущую версию RoofForge alpha в **Edit → Preferences → Get Extensions** (найди RoofForge и отключи/удали).
2. Открой страницу Actions: https://github.com/MorenDord/RoofForge_Blender/actions
3. Выбери последний успешный workflow **RoofForge tests** на ветке `feature/0.2.0-arbitrary-contours-live-pitch`.
4. В разделе **Artifacts** скачай внешний архив `roof_forge-0.2.0-alpha.6-blender-5.0.1.zip`.
5. Распакуй внешний архив один раз. Внутри будет `roof_forge-0.2.0-alpha.6.zip` и файл SHA256.
6. Внутренний `roof_forge-0.2.0-alpha.6.zip` **не распаковывай**.
7. В Blender открой **Edit → Preferences → Get Extensions**.
8. В меню установки выбери **Install from Disk…**, укажи внутренний ZIP, установи и включи RoofForge.
9. В 3D View нажми **N** и открой вкладку **RoofForge**.

## Первый тест — выпуклый контур

1. Создай Mesh с одним замкнутым контуром. Это может быть wire loop из рёбер или поверхность с одной внешней граничной петлёй.
2. Выдели только объект. Выделение вершин/рёбер не требуется.
3. Нажми **Load / Refresh Slope Angles**.
4. Убедись, что появилось нужное число полей `Edge 01`, `Edge 02` и т. д.
5. Новые поля Pitch сразу получают значение 30°. Установи нужные индивидуальные углы, например 30°, 35°, 40°, 32°.
6. Оставь **Live Update** включённым.
7. Нажми **Create / Update Roof**. Проверка геометрии запускается автоматически при создании; отдельной кнопки Validate больше нет.

Должен появиться отдельный mesh-объект с закрытой толщиной. Исходная сетка не должна измениться.

## Размеры и свес карниза

Все линейные поля RoofForge задаются в **сантиметрах** независимо от того, как Blender отображает единицы в сцене. Начальная толщина крыши — **1 см**, начальный Pitch каждого нового ската — **30°**. Blender переводит сантиметры во внутренние координаты с учётом `Scene → Units → Unit Scale` (`scale_length`). Для точных физических размеров примени масштаб исходного объекта (`Ctrl+A → Scale`).

Параметр **Eave Overhang (cm)** задаёт горизонтальный вынос крыши за исходный контур. Проверь, например, значение 25 см.

- Контур расширяется наружу единым miter-offset на заданное горизонтальное расстояние.
- Верхняя поверхность пересчитывается как общая нижняя огибающая исходных плоскостей. Соседние скаты соединяются по реальной линии пересечения плоскостей; отдельные полосы не могут выступать за соседние.
- Работают индивидуальные Pitch на выпуклых контурах, а также на проверенных вогнутых L/U-контурах.
- Тот же путь применяется к неплоским XYZ-контурам.
- Если большой свес схлопывает узкую вогнутую часть или offset пересекает сам себя, RoofForge выдаёт ошибку и не создаёт повреждённую сетку.

## Второй тест — вогнутый L/U-контур

Для проверки нового алгоритма создай L- или U-образный замкнутый wire-контур, у которого все вершины лежат на одной высоте Z. Теперь можно проверить ненулевой свес.

1. В Object Mode выбери объект.
2. Нажми **Load / Refresh Slope Angles**.
3. Задай разные углы хотя бы для нескольких скатов.
4. Установи **Eave Overhang = 10–15 см**.
5. Создай крышу кнопкой **Create / Update Roof**. Невалидная геометрия будет отклонена с сообщением в панели.
6. Нажми **Create / Update Roof**.
7. После генерации измени один из углов. При Update delay = 0 перестройка должна запускаться без дополнительной debounce-паузы; поставь 150–300 мс, если нужно объединять быстрые изменения ползунка.
8. Измени Thickness (cm): Live Update должен пересчитать оболочку. Значение по умолчанию — 1 см.
9. Сравни положение исходного контура и крыши; исходный mesh остаётся нетронутым.

В этой версии номера скатов следуют детерминированному порядку обхода границы. Цветного выделения соответствующего ребра во viewport и графического плана крыши пока нет.

## Известные ограничения weighted wavefront

- Контуры сложнее проверенных L/U и радиальных семейств могут содержать неоднозначные одновременные события; в таких случаях генератор должен вернуть ошибку, а не неполную крышу.
- Два специальных multi-notch сценария пока исключены из автоматических тестов как известная проблема alpha. Не используй сложные многозубчатые контуры как критерий стабильности.
- Контуры свыше 64 рёбер теперь явно отклоняются.

## Проверка 3D-контура с разной высотой Z

Для проверки 3D-пути попробуй выпуклый четырёх- или многоугольный контур с вершинами на разных высотах Z и ненулевым свесом. RoofForge не должен сплющивать исходные координаты. Если исходные плоскости не дают непрерывную крышу, валидатор должен вернуть ошибку вместо повреждённого меша.

**Важно:** новый weighted wavefront в этой alpha работает только для контура с постоянной высотой карнизов. Вогнутые L/U-контуры с разными Z пока не являются поддерживаемым гарантированным случаем.

## Повторное создание после удаления крыши

1. Создай крышу из исходного контура.
2. Удали только сгенерированный объект крыши.
3. Не меняя исходный контур, снова нажми **Create / Update Roof**.
4. Должен появиться новый объект крыши, привязанный к активной сцене. Это отдельная регрессионная проверка alpha.5.

## Как работает Live Update

- Ползунок **Update delay (ms)** задаёт debounce от 0 до 1000 мс; по умолчанию 0 мс.
- При 0 мс принудительная задержка debounce отсутствует: обновление ставится в очередь на следующий тик таймера Blender. Сам расчёт геометрии всё равно требует вычислений в основном потоке.
- При ненулевом значении быстрые изменения объединяются, и перестройка начинается после выбранной паузы.
- Поверхность кэшируется отдельно от толщины: изменение только Thickness повторно использует существующую верхнюю поверхность и пересобирает только закрытую оболочку.
- Геометрия строится и проверяется до замены mesh.
- Если новый результат невалиден, прежняя корректная крыша остаётся в сцене.
- Переименование исходного объекта или сгенерированной крыши останавливает Live Update. Это защищает от случайного изменения объекта после начала ручной доработки.
- Если число рёбер исходного контура изменилось, нажми **Load / Refresh Slope Angles** и проверь соответствие углов заново.

## Что пока не реализовано

- Поддержка абсолютно любых wavefront event-комбинаций; некоторые multi-notch контуры и комбинации одновременных split/collapse событий пока отклоняются.
- Offset-контуры с самопересечением, схлопнувшимися сегментами или слишком узкими вогнутыми частями отклоняются. Уменьши свес или измени исходный контур.
- Цветная подсветка связи «номер ската ↔ ребро» и графическая карта pitch.
- Автоматические коньки, ендовы, standing seams, UV, LOD и экспорт.
- Не все сложные multi-notch / simultaneous split-collision event-сценарии weighted wavefront пока поддерживаются.

## Что прислать после проверки

Для каждой проблемы полезно приложить:
- версию Blender (**Help → About Blender**) и ОС;
- количество рёбер и тип контура: выпуклый, L, U, multi-notch или произвольный;
- высоты Z вершин, если они различаются;
- список значений Pitch;
- скриншот результата и панели RoofForge;
- точный текст ошибки из Blender System Console;
- небольшой `.blend` с исходным контуром, если ошибка воспроизводится.

Особенно интересуют случаи, где:
- не совпадает номер ската и ожидаемое ребро;
- Live Update создаёт дубликат или не сохраняет последнюю крышу;
- крыша имеет разрыв, самопересечение или неверную плоскость ската;
- результат на L/U отличается от ожидаемого.

## Удаление alpha

В **Preferences → Get Extensions** отключи/удали RoofForge. Перед установкой следующей alpha рекомендуется удалить предыдущую тестовую версию.
