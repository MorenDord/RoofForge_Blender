# RoofForge 0.2.1 — установка и тестирование

Это тестовая сборка для Blender 5.0+. Первая кнопка **Create / Update Roof** сама считывает активный Mesh-контур и создаёт Pitch-поля — действие Load / Refresh Slope Angles больше не нужно. После генерации доступны индивидуальные углы, толщина, свес, настройка схождения внешних углов и Live Update.

Миниатюра строится по фактическим граням крыши. Во время изменения параметров остаётся предыдущее изображение; новая PNG-миниатюра создаётся один раз после завершения серии обновлений. Это освобождает Live Update от повторной растеризации картинки.


## Установка

1. Удали предыдущую версию RoofForge alpha в **Edit → Preferences → Get Extensions** (найди RoofForge и отключи/удали).
2. Открой страницу Actions: https://github.com/MorenDord/RoofForge_Blender/actions
3. Выбери последний успешный workflow **RoofForge tests** на ветке `feature/0.2.0-arbitrary-contours-live-pitch`.
4. В разделе **Artifacts** скачай внешний архив `roof_forge-0.2.1-blender-5.0.1.zip`.
5. Распакуй внешний архив один раз. Внутри будет `roof_forge-0.2.1.zip` и файл SHA256.
6. Внутренний `roof_forge-0.2.1.zip` **не распаковывай**.
7. В Blender открой **Edit → Preferences → Get Extensions**.
8. В меню установки выбери **Install from Disk…**, укажи внутренний ZIP, установи и включи RoofForge.
9. В 3D View нажми **N** и открой вкладку **RoofForge**.

## Первый тест — выпуклый контур

1. Создай Mesh с одним замкнутым контуром. Это может быть wire loop из рёбер или поверхность с одной внешней граничной петлёй.
2. Выдели только объект. Выделение вершин/рёбер не требуется.
3. Нажми **Create / Update Roof**. RoofForge автоматически создаст нужные Pitch-поля.
4. Убедись, что появилось нужное число полей Pitch.
5. Новые поля Pitch сразу получают значение 30°. Установи разные индивидуальные углы, например 30°, 35°, 40°, 32°.
6. Нажми **Create / Update Roof**: после генерации над Pitch-полями появится миниатюра реальных скатов с внутренними линиями переломов. Номер внутри ската соответствует строке Edge с тем же номером.
7. Измени **Number size** для размера цифр и **Line thickness** для толщины белых линий. Новая миниатюра появится после короткой паузы; во время изменения ползунков старое изображение остаётся на месте.
8. Установи **Overhang = 25 см** и оставь **Converge corners** включённым.
9. Оставь **Live Update** включённым.
10. Нажми **Create / Update Roof**. Проверка геометрии запускается автоматически при создании; отдельной кнопки Validate больше нет.

Должен появиться отдельный mesh-объект с закрытой толщиной. Исходная сетка не должна измениться.

## Как теперь строится свес

Параметр **Eave Overhang (cm)** задаёт горизонтальное расстояние, на которое продолжается крыша за исходный контур.

1. RoofForge строит плоскости скатов через исходные 3D-рёбра карниза. Их положение и высоты не сдвигаются.
2. Наружный offset используется только как расширенная XY-область, которую покрывают эти же плоскости.
3. Опорная/нижняя поверхность сохраняет исходную геометрию на контуре; если включён свес, толщина оболочки добавляется вверх от этой поверхности.
4. В итоге кровля продолжается наружу за линию карниза, но сама линия опоры остаётся на исходном месте. Независимые полосы и угловые заглушки не добавляются.
5. Внутренние копланарные рёбра растворяются в меше. Реальные рёбра перелома скатов остаются.

Опция **Converge corners** строит одну общую точку на каждом углу внешнего контура: обе соседние плоскости скатов проходят через неё. Поэтому длина свеса может различаться вдоль сторон — это ожидаемо. Если отключить опцию, применяется прежний равномерный miter-offset.

Если внешний контур самопересекается, схлопывается или соседние плоскости не имеют подходящей внешней точки пересечения, RoofForge отклонит построение и сохранит предыдущую корректную крышу.


> **Ограничение 0.2.1:** режим свеса с сохранением нижней поверхности на исходном контуре пока доступен только для выпуклых контуров. Вогнутые L/U-контуры можно строить с нулевым свесом; при положительном свесе генератор остановится с диагностикой вместо создания разорванной крыши.


## Второй тест — вогнутый L/U-контур

Для проверки concave offset создай L- или U-образный замкнутый wire-контур, у которого все вершины лежат на одной высоте Z.

1. В Object Mode выбери объект.
2. Нажми **Create / Update Roof**.
3. Задай разные углы хотя бы для нескольких скатов.
4. Установи **Eave Overhang = 10–15 см**.
5. Создай крышу кнопкой **Create / Update Roof**.
6. Проверь, что внешний контур идёт одной непрерывной петлёй: в углах не должно быть выступающих полос, ответвлений или отдельных треугольных вееров.
7. Попробуй увеличить свес так, чтобы узкая впадина U почти схлопнулась. В таком случае ожидается понятная ошибка, а не самопересекающаяся сетка.
8. После генерации измени один из углов. При Update delay = 0 перестройка должна запускаться без дополнительной debounce-паузы; поставь 150–300 мс, если нужно объединять быстрые изменения ползунка.
9. Измени Thickness (cm): Live Update должен пересчитать оболочку. Значение по умолчанию — 1 см.

## Проверка 3D-контура с разной высотой Z

Для проверки 3D-пути попробуй выпуклый четырёх- или многоугольный контур с вершинами на разных высотах Z и ненулевым свесом. Смещение по горизонтали не должно менять Z соответствующих вершин. RoofForge не должен сплющивать исходные координаты. Если исходные плоскости не дают непрерывную крышу, валидатор должен вернуть ошибку вместо повреждённого меша.

**Важно:** weighted wavefront работает только для контура с постоянной высотой карнизов. Вогнутые L/U-контуры с разными Z пока не являются гарантированным случаем.

## Повторное создание после удаления крыши

1. Создай крышу из исходного контура.
2. Удали только сгенерированный объект крыши.
3. Не меняя исходный контур, снова нажми **Create / Update Roof**.
4. Должен появиться новый объект крыши, привязанный к исходному контуру.
5. Отредактируй исходный контур в Edit Mode, вернись в Object Mode и снова нажми **Create / Update Roof**. Геометрия крыши должна пересчитаться с обновлёнными координатами.

## Как работает Live Update

- Ползунок **Update delay (ms)** задаёт debounce от 0 до 1000 мс; по умолчанию 0 мс.
- При 0 мс принудительная задержка debounce отсутствует: обновление ставится в очередь на следующий тик таймера Blender. Сам расчёт геометрии всё равно требует вычислений в основном потоке.
- При ненулевом значении быстрые изменения объединяются, и перестройка начинается после выбранной паузы.
- Поверхность кэшируется отдельно от толщины: изменение только Thickness повторно использует существующую верхнюю поверхность и пересобирает только закрытую оболочку.
- Геометрия строится и проверяется до замены mesh.
- Если новый результат невалиден, прежняя корректная крыша остаётся в сцене.
- Переименование исходного объекта или сгенерированной крыши останавливает Live Update.
- Если число рёбер исходного контура изменилось, нажми **Create / Update Roof**: список Pitch-полей будет автоматически создан заново.

## Известные ограничения

- Поддерживается один простой замкнутый контур. Отверстия и несколько независимых петель не поддерживаются.
- Режим свеса пока доступен только для выпуклых контуров; вогнутые L/U-контуры без свеса поддерживаются. При включённом свесе вогнутый контур будет отклонён.
- Максимум 64 ребра.
- Offset-контур, который самопересекается, схлопывается или имеет miter длиннее 50 ширин свеса, отклоняется.
- Некоторые multi-notch и одновременные split/collapse события weighted wavefront остаются ограничением alpha.
- Произвольные вогнутые mixed-Z контуры пока не гарантируются.
- Рёбра нумеруются на схеме сверху; номер совпадает с одноимённым Pitch-полем. Для изменения уклона редактируй числовое поле — переходить в Edit Mode не нужно. Пока пользователь двигает параметры крыши, миниатюра не перерисовывается; изображение обновляется после паузы.
- Автоматические коньки, ендовы, standing seams, UV, LOD и экспорт пока не реализованы.

## Что прислать после проверки

Для каждой проблемы полезно приложить:
- версию Blender (**Help → About Blender**) и ОС;
- количество рёбер и тип контура: выпуклый, L, U или multi-notch;
- высоты Z вершин, если они различаются;
- список значений Pitch и Eave Overhang;
- скриншот результата и панели RoofForge;
- точный текст ошибки из Blender System Console;
- небольшой `.blend` с исходным контуром, если ошибка воспроизводится.

Особенно интересуют случаи, где:
- номер на схеме не соответствует одноимённому Pitch-полю или не помещается внутри сложного контура;
- внешний свес не является одной непрерывной петлёй;
- индивидуальные Pitch сопоставились не с теми рёбрами;
- Live Update создаёт дубликат или не сохраняет последнюю корректную крышу;
- крыша имеет разрыв, самопересечение или неверную плоскость ската.

## Удаление alpha

В **Preferences → Get Extensions** отключи/удали RoofForge. Перед установкой следующей alpha рекомендуется удалить предыдущую тестовую версию.
