# RoofForge 0.2.4 — установка и тестирование

Экспериментальная сборка для Blender 5.0+. Векторная схема GPU/BLF встроена в основную вкладку **RoofForge** N-панели: отдельной вкладки **Roof Plan** больше нет.

## Отображение схемы

- **Raster preview (PNG)** — кэшированная миниатюра в основной вкладке RoofForge; обновляется отложенно после завершения изменений.
- **Vector preview** — схема рисуется напрямую GPU/BLF в зарезервированной области той же вкладки RoofForge, между настройками отображения и списком Pitch.
- Оба режима можно включать одновременно. PNG отображается первым, ниже — векторная схема. Можно отключить любой или оба режима.
- В режиме только Vector PNG-рендерер не запускается. GPU использует кэшированную геометрию.
- Когда содержимое N-панели прокручено вниз от верхней позиции, закреплённая GPU-схема скрывается, чтобы не перекрывать поля Pitch и остальные настройки. Вернись к верху вкладки, чтобы снова увидеть схему.

## Установка

1. Удали предыдущую тестовую версию RoofForge в **Edit → Preferences → Get Extensions**.
2. Открой Actions: https://github.com/MorenDord/RoofForge_Blender/actions
3. Выбери последний успешный workflow **RoofForge tests** на ветке `feature/0.2.0-arbitrary-contours-live-pitch`.
4. Скачай внешний архив `roof_forge-0.2.4-blender-5.0.1` и распакуй его один раз.
5. Установи внутренний `roof_forge-0.2.4.zip` через **Preferences → Get Extensions → Install from Disk…**. Внутренний ZIP не распаковывай.

## Проверка основной вкладки

1. Выдели Mesh-контур и нажми **Create / Update Roof** во вкладке **RoofForge** (клавиша N в 3D Viewport).
2. В блоке Plan display отключи **Raster preview (PNG)** и включи **Vector preview**.
3. Схема должна появиться в той же вкладке RoofForge — между настройками Plan display и списком Pitch. Переключаться на другую вкладку N-панели не нужно.
4. Измени Pitch, толщину и свес. Схема должна обновляться без генерации PNG.
5. Проверь, что Pitch-поля ниже схемы доступны и схема их не перекрывает.
6. Измени ширину N-панели, масштаб интерфейса и высоту окна Blender. Схема должна оставаться внутри зарезервированной области и подстраиваться под доступный размер.
7. Прокрути N-панель вниз: GPU-схема должна скрыться, а поля Pitch и остальные параметры должны оставаться доступными. Верни прокрутку к верху — схема должна появиться снова.
8. Включи оба режима: PNG должен отображаться над векторной схемой в той же вкладке. Выключи оба режима: оба представления должны исчезнуть, генерация крыши и Live Update должны продолжать работать.

## Остальные проверки

- Сравни производительность в режимах PNG-only, Vector-only и Both.
- Проверь несколько окон 3D Viewport, изменение размеров панели и переключение вкладок.
- Убедись, что после отключения аддона draw-handler освобождается.
- Убедись, что PNG не пересоздаётся при отключённом Raster preview.

Остальные возможности генератора сохранены: индивидуальный Pitch, толщина, свес с опцией Converge corners, Live Update, повторное создание после удаления крыши и перестройка после редактирования исходного контура в Edit Mode.

Положительный свес поддерживается только для выпуклых контуров. Вогнутые L/U-контуры поддерживаются при нулевом свесе; положительный свес для них будет отклонён.
