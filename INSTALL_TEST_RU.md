# RoofForge 0.2.3 — установка и тестирование

Экспериментальная сборка для Blender 5.0+. Добавлен прямой GPU-рендеринг схемы крыши **внутри N-панели** (регион `UI`), без PNG.

## Два способа отображения

- **Raster preview (PNG)** — прежняя миниатюра в основной вкладке **RoofForge**. PNG обновляется отложенно после короткой паузы.
- **Vector preview (N-panel)** — схема рисуется GPU/BLF непосредственно в отдельной вкладке **Roof Plan** в N-панели 3D Viewport. Это не оверлей над 3D-сценой.
- Оба режима можно включать одновременно: PNG будет в RoofForge, вектор — во вкладке Roof Plan. Можно отключить любой или оба.
- Если PNG выключен, генератор PNG вообще не запускается при изменении геометрии и Pitch. Векторный режим использует кэшированную геометрию и только перерисовывает GPU-схему.

## Установка

1. Удали предыдущую тестовую версию RoofForge в **Edit → Preferences → Get Extensions**.
2. Открой Actions: https://github.com/MorenDord/RoofForge_Blender/actions
3. Выбери последний успешный workflow **RoofForge tests** на ветке `feature/0.2.0-arbitrary-contours-live-pitch`.
4. Скачай внешний архив `roof_forge-0.2.3-blender-5.0.1` и распакуй его один раз.
5. Установи внутренний `roof_forge-0.2.3.zip` через **Preferences → Get Extensions → Install from Disk…**. Внутренний ZIP не распаковывай.

## Проверка N-панели

1. Выдели Mesh-контур и нажми **Create / Update Roof** во вкладке **RoofForge**.
2. В блоке Plan display отключи **Raster preview (PNG)** и включи **Vector preview (N-panel)**.
3. Перейди в отдельную вкладку **Roof Plan** на боковой панели 3D Viewport (клавиша N).
4. Векторная схема должна появиться непосредственно в области этой вкладки. Она не должна рисоваться поверх 3D-сцены или закрывать кнопки управления.
5. Измени Pitch, толщину и свес. Схема должна перерисовываться без генерации PNG.
6. Измени ширину N-панели и высоту окна Blender. Схема должна оставаться в пределах вкладки и масштабироваться по доступному размеру.
7. Включи оба режима: PNG появляется во вкладке RoofForge, вектор — в Roof Plan.
8. Выключи оба режима: оба представления исчезают, генерация крыши и Live Update продолжают работать.

## Важное ограничение прототипа

Чтобы GPU-отрисовка не перекрывала обычные элементы управления, векторная схема пока находится в отдельной вкладке N-панели **Roof Plan**, а не в том же вертикальном блоке, где Pitch и остальные настройки. Это первый безопасный вариант прямой отрисовки в UI-регионе. После проверки можно будет попробовать встроить область схемы в основную вкладку RoofForge, но там потребуется точная синхронизация координат с прокруткой UI-панели.

## Остальные проверки

- Сравни производительность в режимах PNG-only, Vector-only и Both.
- Проверь несколько окон 3D Viewport, изменение размеров панели и переключение вкладок.
- Убедись, что после отключения аддона draw-handler освобождается.
- Убедись, что PNG не пересоздаётся при отключённом Raster preview.

Остальные возможности генератора сохранены: индивидуальный Pitch, толщина, свес с опцией Converge corners, Live Update, повторное создание после удаления крыши и перестройка после редактирования исходного контура в Edit Mode.

Положительный свес поддерживается только для выпуклых контуров. Вогнутые L/U-контуры поддерживаются при нулевом свесе; положительный свес для них будет отклонён.
