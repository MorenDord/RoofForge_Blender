# RoofForge 2.9.0 — пространственные крыши и профили узлов

RoofForge 2.9.0 создаёт низкополигональные крыши из замкнутого граничного контура карниза. Поддерживается один режим: **«Вальмовая / свободные углы»**. Контур может быть плоским или пространственным; каждому ребру можно назначить собственный угол ската.

Минимальная версия Blender — **5.0.0**. Регистрация аддона, генерация крыш, обновление профилей и сохранение/повторное открытие проекта проверены в headless Blender **5.2.3 LTS**.

## Основные возможности

- Индивидуальный угол для каждого ребра карниза — до 32 рёбер. Работает и на плоском контуре, а не только при перепадах высот.
- Вогнутые и выпуклые планы, в том числе Г-/П-образные, косоугольные и многорефлексные контуры.
- Разные высоты вершин неплоского карниза; исходные XYZ не выравниваются.
- Свес по плоскости каждого ската, с сопряжением соседних полос в углах.
- Реальная толщина mesh-геометрией: нижняя поверхность, верхняя поверхность и боковые стенки. Толщина по умолчанию — 0.01 м.
- Отдельные объекты коньков и ендов, создаваемые по фактическим стыкам соседних граней крыши.
- Отдельные команды «Создать на выбранной крыше» и «Обновить» для коньков и ендов. Эти команды читают готовую геометрию и сохранённую исходную поверхность; крышу через straight-skeleton повторно не перестраивают.
- Пространственная фальцевая раскладка: продольные рёбра идут по поверхности ската, высота ограничена 90% высоты конька. Изменение настроек фальцев пересобирает только mesh фальцев.
- Поддержка готовых Mesh-крыш с небольшой локальной неплоскостностью граней. Сильно искривлённые импортированные грани отклоняются, а не аппроксимируются молча.

## Пространственный решатель и его границы

Для плоского контура с разными углами используется взвешенный волновой фронт: времена схождения и разделения рёбер пересчитываются с учётом скорости каждого ребра.

Для неплоского контура строится топология скатов, затем вершины переносятся на индивидуальные 3D-опорные плоскости рёбер карниза. Узлы согласуются с ограниченным допуском; микроскопические событийные щели обрабатываются отдельно. После этого выполняется проверка покрытия исходного карниза, связности и самопересечений.

Это **не универсальный аналитический 3D weighted straight-skeleton для любых возможных высот и углов**. Поэтому некоторые математически несовместимые или численно неоднозначные сочетания будут отклонены с диагностикой. Аддон не должен закрывать такие случаи произвольными гранями или тихо уплощать исходный контур.

Обязательные тесты покрывают плоские Г-/П-планы с индивидуальными углами, неплоские Г-/П-планы с перепадами карниза до 0.20–0.24 м, косоугольный многорефлексный план и 12-рёберный крестообразный контур с четырьмя вогнутыми углами. Проверяются также свес, профили коньков/ендов и пространственные фальцы. Для конфигураций за пределами проверенной области следует считать отказ решателя ожидаемым безопасным поведением, пока конкретный случай не добавлен в регрессионный набор.

## Свес карниза

На плоском контуре свес задаётся в горизонтальной плоскости. На пространственном — как расстояние по плоскости соответствующего ската, перпендикулярно его 3D-кромке. Полосы соседних граней сопрягаются общей угловой геометрией; вместо двух независимых лучей от крайней точки не создаются несвязанные участки.

Исходная поверхность крыши до свеса сохраняется отдельно. Благодаря этому коньки и ендовы строятся по фактическим граням крыши, а не по дополнительным переходным граням свеса.

## Коньки и ендовы

Стыки извлекаются из реального mesh крыши. Классификация использует соседние грани и знак двугранного угла. Для профиля строятся inset-полосы на обеих сторонах стыка, затем отдельная геометрия экструдируется над поверхностью.

Многоветвевые узлы обрабатываются общей переходной поверхностью, упорядоченной по секторам соседних граней. Это устраняет многократное использование одной вертикальной кромки и не требует накладывать независимые заглушки в одном узле. Неплоскостность анализируется локально по граням, а не как единое требование к объекту целиком.

Коньки и ендовы имеют signed-параметр «Смещение концов»: положительное значение выдвигает конец наружу, отрицательное отодвигает его внутрь.

## Предпросмотр скатов

Схема в панели — вид сверху реальной поверхности крыши с контурами отдельных скатов. Фон PNG прозрачный, линии белые, тонкие и сглаженные supersampling-рендерингом. Угол каждого ската влияет на геометрию схемы. Номер размещается в свободной центральной области соответствующего ската и автоматически уменьшается, если контур узкий. Размер цифр отдельно не регулируется; масштаб всей схемы подстраивается под ширину панели.

## Автоматические проверки

Обязательные CI-группы на текущем кандидате:

- 36 тестов пространственной геометрии, многоветвевых профилей и предпросмотра;
- 24 теста свеса и профильных сопряжений;
- 53 регрессионных теста существующего геометрического ядра;
- headless runtime и round-trip в Blender 5.2.3 LTS: создание крыш, коньков, ендов и фальцев, сохранение .blend, открытие во втором процессе и повторное обновление профилей.

Экспериментальный модуль взвешенного волнового фронта также имеет отдельный non-gating probe. Он не является заменой проверенного пути для неплоских равномерных скатов; два прямых эксперимента на неплоском L-контуре пока остаются известными неуспешными сценариями экспериментального модуля.

## Установка

Установите собранный roof_forge_2.9.0.zip через Blender → Preferences → Get Extensions → Install from Disk. В ZIP-файле blender_manifest.toml и __init__.py находятся в корне пакета. После установки включите RoofForge и откройте View3D → Sidebar → RoofForge.

Перед использованием на рабочем проекте проверьте конкретные углы и высоты на копии сцены. При ошибке пространственного решателя сохраните контур и текст диагностики: это корректный отказ, а не повод пропускать проверки.
