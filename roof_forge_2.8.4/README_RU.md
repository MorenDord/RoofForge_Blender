# RoofForge 2.8.4 — чертёжная схема скатов и пространственные узлы

RoofForge сохраняет прежнее низкополигональное ядро straight-skeleton для плоских контуров и добавляет отдельную экспериментальную ветку для неплоских контуров карниза. Режим крыши в интерфейсе по-прежнему один: **«Вальмовая / свободные углы»**.

## Исправление совместимости импорта в 2.8.4

Пространственное ядро переименовано в уникальный модуль `spatial_roof_2_8_4.py`, а все импорты и тесты переключены на него. Это исключает конфликт старого кэшированного `spatial_roof_2_8_0.py` после обновления расширения поверх предыдущей установки.

## Чертёжная схема индивидуальных скатов

В пространственном режиме панель показывает чёрно-белый план карниза сверху: белое поле, чёрный контур и простые цифры без кружков. Масштаб схемы подстраивается под ширину панели; отдельный ползунок «Размер цифр» регулирует только номера. На каждом ребре стоит номер; настройки ниже подписаны тем же номером: **номер ребра на схеме = номер параметра «Скат N»**. Нумерация идёт по порядку обхода сохранённого граничного loop. Поддерживаются двузначные номера.

## Пространственная крыша

- Для каждой вершины карниза сохраняются исходные XYZ-координаты; высоты не выравниваются.
- Для каждого ребра можно задать собственный угол ската (до 32 рёбер).
- Плоскость каждого ската проходит через соответствующее 3D-ребро карниза. Построение проверяет, что заданные высоты и углы дают непрерывную нижнюю огибающую, закрывающую весь карниз.
- Значение **«Свес карниза»** для пространственного режима измеряется по плоскости соответствующего ската, перпендикулярно его 3D-кромке. Каждый граничный сегмент получает собственную плоскую полосу; угловые переходы соединяются треугольными участками. Толщина добавляется после свеса.
- Сохранены вертикальный подъём и реальная mesh-экструзия толщины.

### Ограничение пространственного решателя

Текущий решатель надёжно проверен на выпуклых неплоских контурах, включая прямоугольники с наклонными рёбрами и разными углами. Он **пока не является полноценным 3D straight-skeleton для вогнутых Г-/П-контуров**: некоторые такие конфигурации отклоняются проверкой покрытия карниза. В частности, базовый неплоский Г-контур пока не считается поддержанным. Алгоритм должен получить отдельный пространственный граф узлов, который сможет корректно формировать ветви ендов и схлопывания в рефлексных углах. Аддон выдаёт ошибку для незамкнутой поверхности, а не подделывает её.

## Коньки и ендовы на пространственных поверхностях

Профили определяются по фактическим рёбрам между соседними 3D-гранями. Знак двугранного угла различает выпуклый конёк и вогнутую ендову. Для плоских граней с наклоном по Z профиль строится в их собственной плоскости, а не через плоскую XY-модель.

Для параметрической пространственной крыши RoofForge сохраняет отдельную исходную верхнюю поверхность до добавления свеса. Поэтому команды **«Создать на выбранной крыше»** и **«Обновить»** читают сохранённую поверхность/готовый меш и перестраивают только соответствующий объект профиля; повторный запуск straight-skeleton для этих команд не требуется. Знак «Смещение концов» сохраняется.

Классификатор и построитель профиля проверены на отдельном 3D-примере настоящего вогнутого стыка. При этом генерация Г-/П-образной неплоской крыши пока ограничена решателем выше: наличие 3D-профильного инструмента само по себе не означает, что любой вогнутый пространственный план уже можно сгенерировать.

## Фальцевая кровля

Фальцы сохранены для ранее поддерживаемых плоских крыш. В пространственном режиме этот раздел пока остаётся отключённым: к нему вернёмся после завершения пространственного графа и устойчивого построения вогнутых 3D-контуров.

## Плоский режим и совместимость

Плоские контуры продолжают использовать прежний straight-skeleton и прежний механизм свеса. Прежние функции толщины, профилей и фальцев не переписываются через пространственную ветку.

## Автоматические проверки 2.8.4

В пакет включены регрессионные тесты для прежнего ядра, пространственной схемы, 3D-коньков/ендов и свеса. Они проверяют manifold-соединения профилей, согласованность нумерации, сохранение исходных фасет, замкнутость полос свеса и обработку обратного обхода контура. Полный локальный набор: **55 тестов пройдено**.

Blender runtime в среде сборки отсутствует. Python-компиляция и чистые геометрические тесты не заменяют проверку регистрации свойств, UI и операторов непосредственно в Blender 5.2.2. Перед рабочим использованием проверьте архив на копии проекта.

## Установка

Установите `roof_forge_2.8.4.zip` через Blender → Preferences → Get Extensions → Install from Disk. Минимальная версия в манифесте — Blender 5.0.0.
